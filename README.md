# PaySim Mobile Money Fraud Detection

A machine learning-based mobile-money fraud detection system using a Random Forest classifier.

## Objective

The system identifies potentially suspicious mobile-money transactions using transaction characteristics and behavioral balance-depletion features.

## Model

Random Forest with 200 trees.

## Main behavioral features

- Positive balance depletion
- Account drain ratio
- Remaining balance ratio
- Balance after transaction
- Receiver transaction history
- Transaction amount
- Transaction type

## Deployment

The application is implemented using Streamlit.
